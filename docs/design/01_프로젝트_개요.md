# 프로젝트 개요

> 최종 갱신: 2026-09-04

## 1. 무엇인가

**Oracle AI Database 26ai 의 AI·컨버지드 기능을 한 화면에서 직접 실행해 보는 데모 웹앱.**

Oracle 26ai 가 "무엇을 새로 할 수 있는가"를 슬라이드가 아니라 **실제 SQL 과 실행 결과로**
보여주는 것이 목적이다. 그래서 모든 탭이 공통된 서사를 따른다 —
**같은 질문을 두 방식으로 풀어 나란히 놓고 비교한다.**

| 탭 | 비교하는 것 |
|---|---|
| NL2SQL | 사람이 쓴 SQL ↔ Select AI 가 생성한 SQL |
| AI Vector Search | 키워드 검색 ↔ 의미 검색 (↔ 둘을 합친 하이브리드) |
| JSON Relational Duality | 관계형 JOIN ↔ 같은 데이터의 JSON 문서 |
| Property Graph | 기존 SQL JOIN ↔ SQL/PGQ 그래프 질의 |
| 개발생산성 향상 | 기존 잠금 방식 ↔ Lock-Free / Priority Transactions |
| 기타 부가 기능 | (AWR 리포트를 LLM 이 읽고 성능 분석) |

**대상**: Oracle 26ai 를 처음 접하는 개발자·DBA. UI 는 전부 한국어.

## 2. 6개 탭

| # | 탭 | 핵심 Oracle 기능 | 모듈 |
|---|---|---|---|
| 1 | NL2SQL(Select AI) | `DBMS_CLOUD_AI.GENERATE` / `SET_PROFILE`, Annotation | `select_ai.py` |
| 2 | AI Vector Search | `VECTOR_EMBEDDING`, `VECTOR_DISTANCE`, HNSW, Oracle Text | `vector_search.py` |
| 3 | JSON Relational Duality | `JSON RELATIONAL DUALITY VIEW`, ETag 동시성 | `duality.py` |
| 4 | Property Graph | `CREATE PROPERTY GRAPH`, `GRAPH_TABLE(... MATCH ...)` | `graph.py` |
| 5 | 개발생산성 향상 | Lock-Free Reservations, Priority Transactions | `productivity.py` |
| 6 | 기타 부가 기능 | AWR HTML 파싱 + 외부 LLM 분석 | `awr_analyzer_v2.py` |

## 3. 기술 스택

| 층 | 기술 | 비고 |
|---|---|---|
| 백엔드 | Python 3.12 · FastAPI · uvicorn | 단일 프로세스 |
| DB 드라이버 | python-oracledb **thin** | Instant Client 불필요 |
| DB | Oracle Autonomous Database 26ai (23.26.3.2.0) | ADMIN 스키마 |
| 프론트 | Vue 3 (CDN) · Chart.js · Jinja2 | **빌드 불필요** — Phase 5 에서 SPA 이식 예정 |
| 임베딩 | DB 내장 ONNX (`MULTILINGUAL_E5_BASE`, 768차원) 또는 외부 API | 런타임 전환 |
| LLM | Groq (Llama 3.3 70B) · Google Gemini 2.5 Flash | RAG 답변·AWR 분석 |
| 스케줄러 | APScheduler | ADB Keepalive 주 1회 |
| 운영 | macOS launchd 상시 구동 (:8247) | 자동 리로드 없음 |

## 5. 자매 프로젝트

**InvestHub** (`~/Dev/investhub`) — 이 앱의 핵심 모듈(DB 풀, LLM 클라이언트, SSE 스트리밍,
Vector Search 패턴)을 이식해 만든 개인 투자 플랫폼. 2026-05 부터 개발되어 현재는
Vue 3 + TypeScript + Vite SPA 로 훨씬 성숙해 있다.

**관계가 역전되어 있다**: db26ai-demo 가 InvestHub 의 모태였지만, 지금은
**InvestHub 의 UI·작업 규율을 db26ai-demo 로 역이식**하는 중이다
(`docs/개발노하우.md`, `docs/ROADMAP.md` Phase 4·5).
